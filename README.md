PROYECTO DE PRÁCTICA PARA DOMINAR BÁSICOS DE HTML Y CSS

Este es un proyecto de práctica con el fin de dominar los temas básicos de HTML y CSS, abarcando los temas como las diversas etiquetas para la estructura de un documento HTML
así como modificar el estilo de cada segmento dándole un diseño más atractivo a la vista, aprendiendo a importar fuentes y figuras personalizadas a la estructura para mejorar su diseño

Este proyecto trata de una página web para freelancer señalando las aptitudes y los tipos de trabajo en los que puede trabajar
